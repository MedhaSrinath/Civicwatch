# CivicWatch

## Smart Civic Issue Reporting and Resolution Platform

CivicWatch is a full-stack web application that enables citizens to report civic issues such as potholes, garbage accumulation, broken streetlights, damaged roads, drainage problems, and water leakage using photos and location details.

Reported issues are categorized and assigned to the appropriate department, allowing officials to manage, prioritize, and track complaints through their resolution lifecycle. Administrators can monitor complaints, resolution progress, and overall civic service performance through a centralized dashboard.

---

## 🎯 Objectives

- Enable citizens to easily report civic issues.
- Support photo and location-based issue reporting.
- Organize complaints based on categories and departments.
- Allow officials to manage and track assigned complaints.
- Enable citizens to monitor complaint status and resolution.
- Provide administrators with centralized monitoring and analytics.
- Store and manage application data securely using a database.

---

## 👥 User Roles

### 👤 Citizen
- Register and log in
- Report civic issues
- Upload issue photographs
- Provide location and description
- Track submitted complaints
- View complaint history
- Provide feedback on resolutions

### 👨‍💼 Officer
- Log in to the officer dashboard
- View assigned complaints
- Prioritize and manage issues
- Update complaint status
- Add remarks
- Upload resolution evidence

### 🛡️ Administrator
- Manage users
- Manage departments and issue categories
- Assign and reassign complaints
- Monitor complaints
- Manage reported issues
- View system and departmental analytics
